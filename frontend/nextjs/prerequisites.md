## Prerequisites

Before creating a Next.js project, ensure the following software is installed:

1. **Node.js (LTS)** – Required JavaScript runtime for running Next.js.
   - Download: https://nodejs.org/
   - Install the latest LTS version.

2. **npm** – Node.js package manager, automatically installed with Node.js.

3. **Visual Studio Code** – Recommended code editor.
   - Download: https://code.visualstudio.com/

### Verify Installation

Open PowerShell or the VS Code terminal and execute:

```powershell
node -v
npm -v
```

Both commands should display their installed version numbers.

**Note:** No separate installation of React, Next.js, TypeScript, or Tailwind CSS is required. These are installed and configured automatically when creating the project using `create-next-app`.
